1. SALUDO
Buenos(as) (días, tardes, noches) bienvenido a la Superintendencia Nacional de Salud, me presento, mi nombre es __________ ¿En qué le puedo colaborar?
Se indica al inicio de la conversación, se debe presentar con nombre y apellido. Establezca contacto visual con el usuario. Aplica para todas las gestiones.
2. HABEAS DATA
¿En cumplimiento de la Ley 1581 de 2012, autoriza a la Superintendencia Nacional de Salud a tratar sus datos personales para su respectiva gestión interna?
Se debe utilizar en todas las gestiones, antes de empezar a solicitar los datos del peticionario o afectado. Si el usuario no autoriza el tratamiento de datos personales, se debe persuadir indicándole la importancia. Aplica para todas las gestiones.
PERSUADIR AUTORIZACIÓN HABEAS DATA
Sr(a). ___________ Sr(a)____________ para poder registrar su solicitud, es importante que Ud. nos autorice el tratamiento de sus datos personales, de esta manera la entidad podrá verificar la información dentro de sus bases de datos y lo contactarán para brindarle respuesta a su requerimiento.
Se debe indicar para persuadir cuando el usuario no acepta el tratamiento de datos personales. Si el usuario insiste en no autorizar el tratamiento de datos personales, se debe indicar el guion invitándolo a radicar su requerimiento a través de la página de la Supersalud. CUANDO USUARIO NO AUTORICE HABEAS DATA
CUANDO NO AUTORIZA HABEAS DATA
Sr(a) teniendo en cuenta lo manifestado frente al tratamiento de datos, lo invito a que realice su solicitud a través de la página de la Supersalud en la sección del formulario WEB.

3. MOTIVO DE CONTACTO
Identifique cuál es el motivo principal de la interacción del usuario.
Aplica para todas las gestiones.
4. PREGUNTA PARA IDENTIFICAR AFECTADO
¿Es usted o la persona afectada?
Validar correctamente quién es el afectado. Aplica para todas las gestiones.
SOLICITUD DATOS PERSONALES
Solicitar nombres completos, documento, teléfono, correo electrónico y demás datos requeridos para registrar la gestión.
Aplica para todas las gestiones.
5. GUION RADICACIÓN
Informar al usuario el número de radicación y los canales disponibles para seguimiento.
Utilizar al finalizar el registro del caso.
CAPTURA DE INFORMACIÓN
Registrar claramente la información suministrada por el usuario dentro del sistema de gestión.
Aplica para nuevas radicaciones.
VIGENCIA DE LAS ÓRDENES O AUTORIZACIONES
Validar vigencia, fechas y condiciones de la orden médica o autorización.
Aplica para radicaciones.
FALLO DE TUTELA
Validar si existe fallo de tutela relacionado con el requerimiento.
Aplica para radicaciones.
SOLICITUD DATOS POBLACIONALES
Solicitar información poblacional cuando aplique para la gestión.
Validar identidad de género, orientación sexual y población especial según corresponda.
INFORMACIÓN DEL RESULTADO DEL TRÁMITE
Brindar al usuario información sobre el resultado del trámite realizado.
Aplica para consultas de estado.
SEGUIMIENTOS
Confirmar datos de identificación, consultar estado actual y registrar la gestión de seguimiento.
Aplica para seguimientos.
GUION DE DESPEDIDA
Gracias por comunicarse con la Superintendencia Nacional de Salud. ¿Hay algo más en lo que pueda colaborar?
Aplica para todas las gestiones.
GUIONES DE APOYO
Incluye orientación sobre:
  • Estado de trámites
  • Consultas de información
  • Radicaciones
  • Riesgo simple
  • Riesgo vital
  • Tiempos de respuesta
  • Actualizaciones
Utilizar cuando sea necesario ampliar la información al usuario.
EPS LIQUIDADAS
Brindar orientación al usuario sobre EPS liquidadas, EPS receptoras y mecanismos de atención correspondientes.
Aplica para todas las gestiones.
